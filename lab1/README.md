# Лабораторная работа №1. Основы HTML

Простая HTML-страница «О себе» по варианту 10 (тема «Книжный червь и писатель»).

## Что внутри

- шапка с заголовком
- пара секций: навыки и проекты
- боковая панель с любимыми авторами
- форма обратной связи
- картинка-аватар (пока заглушка, вставлю свою)

## Как открыть

Просто открыть `index.html` в браузере.

## Что осталось доделать

- вставить имя и фамилию в шапку и подвал
- добавить своё фото вместо `avatar.jpg`
- прогнать через W3C Validator

Проверено в браузере, теги закрыты.
